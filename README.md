## Бот по теме глобального потепления
# Бот решает часть тоесть маленькую проблему от Глобального Потепелние
### Бот изучает и даёт решение проблемы по вопросу (что провоцирует глобальное потепелние?)

### Описание проекта
Мой проект будет способствовать решению проблемы глобального потепления, а также этот проект будет охватывать ЦА подростков, которые могут не знать об этой  актуальной проблеме. Бот даёт какие-то решения и ответы, смотри инструкцию как запустить бота!

### Структура проекта
```
/start - приветствие бота. 
```

```
/help - помощник бота (напишите это и бот выдаст и опишет все команды которые вы можете написать)
```

```
/solution - помощь в решении проблемы глобального потепления
```

```
/test - тест по теме Глобальному Потеплению 
```

### Как установить проект 
1) Установка вирутального окуржения
```
py -m venv venv
```
2) Смена правил о политике винды

```
Set-ExecutionPolicy RemoteSigned -Scope Process
``` 
3) Активация виртуального окружения
```
.\venv\Scripts\Activate.ps1
```
4) Установить необходимые библиотеки
```
pip install -r requirements.txt
```
